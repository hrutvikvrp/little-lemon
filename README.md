# Little Lemon
A React web app about a Chicago restaurant with a table booking feature. Built as a Meta Front-End Developer Capstone project.
## Prerequisites:
Node.js and npm
## Setup:
git clone https://github.com/hrutvikvrp/little-lemon.git, cd little-lemon, npm install
## Running:
npm start, localhost: 3000 opens,
## Tests:
npm test, press a
## Structure:
Routing is handled by Main.js. Logo and links are handled by Nav.js, and Header.js. Homepage sections are handled by HomePage.js. Reservation is handled by BookingForm.js. AvailableTimes logic is handled by reducers.js
